User interactions are monitored within the system
Behavioural data is analysed to determine risk levels

Low-risk users continue normal operation
High-risk users receive targeted interventions (training, alerts, simulations)
User responses are re-evaluated to update behavioural profiles
This feedback-driven loop ensures that mitigation strategies evolve in response to both user behaviour and emerging threat patterns.

Algorithm 1: Adaptive Socio-Technical Risk Mitigation Engine

Input:
    U = Set of users
    B = Behavioural data (clicks, email interactions, login activity)
    T = Threat intelligence data (phishing patterns, anomalies)
    C = Contextual data (time, location, device usage)

Output:
    Adaptive mitigation actions (training, alerts, restrictions)

Begin

FOR each user u in U DO

    Step 1: Collect Behavioural Data
        behaviour_profile ← ExtractBehaviour(B, u)

    Step 2: Analyse Behaviour Patterns
        cognitive_risk ← EvaluateCognitiveBias(behaviour_profile)
        anomaly_score ← DetectAnomalies(behaviour_profile, T)

    Step 3: Contextual Risk Assessment
        context_risk ← EvaluateContext(C, u)

    Step 4: Compute Risk Score
        risk_score ← WeightedSum(cognitive_risk, anomaly_score, context_risk)

    Step 5: Classify Risk Level
        IF risk_score >= HIGH_THRESHOLD THEN
            risk_level ← "HIGH"
        ELSE IF risk_score >= MEDIUM_THRESHOLD THEN
            risk_level ← "MEDIUM"
        ELSE
            risk_level ← "LOW"
        END IF

    Step 6: Trigger Adaptive Response

        IF risk_level = "HIGH" THEN
            TriggerAlert(u)
            AssignTargetedTraining(u)
            EnableStrictMonitoring(u)
            RestrictHighRiskActions(u)

        ELSE IF risk_level = "MEDIUM" THEN
            ScheduleTraining(u)
            IncreaseMonitoring(u)

        ELSE
            ContinueNormalMonitoring(u)

        END IF

    Step 7: Feedback Loop
        UpdateUserProfile(u, behaviour_profile, risk_score)
        AdjustModelParameters()

END FOR

End
