The Problem

Static Technical Controls vs. Human Susceptibility

  • The Vulnerability: Over 90% of successful corporate cyber attacks begin via social engineering (phishing).
  • The Failure of Static Training: Standard annual compliance training fails to change day-to-day behavioral susceptibility.
  • Treating the Sensor, Not the Weakest Link: The ACASTM model treats the human as an active security sensor rather than a static vulnerability.

Behavioral Drift

Without continuous exposure and verification, safety compliance decays rapidly post-training.

Adaptive Shielding

Defenses must dynamically adjust technical bounds based on real-time composite risk telemetry.

Model Overview

The Socio-Technical Adaptive Feedback Loop

  • 1. Human Factors Layer: Contextualizes human susceptibility to psychological triggers (Urgency, Fear, Authority, Trust, Curiosity).
  • 2. Context Awareness Layer: Collects ambient spatial and temporal markers (off-hours, location shifts) dynamically.
  • 3. Behavioural Analytics Layer: Profiles click rate vs. reporting rate to compute cognitive bias risk.
  • 4. Adaptive Decision Engine: Aggregates threat inputs using w₁, w₂, and w₃ algorithms.
  • 5. Security Controls Layer: Triggers access restrictions and account lockdown interventions.
  • 6. Continuous Learning Layer: Deploys gamified training to remediate vulnerabilities.
Mathematical Modeling

Algorithmic Risk Vector Calculation

Risk(u) = w₁·Cognitive(u) + w₂·Anomaly(u) + w₃·Context(u)
w₁ = 0.5 (Behavior weight)
w₂ = 0.3 (Threat weight)
w₃ = 0.2 (Context weight)

Cognitive Bias

Derived from simulated phishing interaction histories: Bias = C_rate - R_rate. Higher click rates escalate susceptibility score.

Anomaly Score

Weights user behavior against global threat feeds. Users clicking links during high-intensity campaigns trigger exponential multipliers.

Context Risk

Monitors system context. Access during unusual local off-hours adds +40. Unknown IP/Location indicators add +60.

Mitigation Tiers

Dynamic Mitigation Thresholds

Low Risk Tier (<40)

Status: Active

Mitigation: None

The user exhibits safe behavior. Account functions normally with unrestricted access.

Medium Risk Tier (40-75)

Status: Guarded

Mitigation: Assigned Training

User displays susceptibility. The system assigns a 'Phishing Refresher' training card.

High Risk Tier (>=75)

Status: Restricted

Mitigation: Access Suspension

Critical susceptibility or compromise. Suspends sensitive systems access until modules are completed.

Comparative Evaluation

ACASTM vs. Legacy Security Models

Legacy Threat Engines

  • Context-Blind: Validates credentials without checking login hour (temporal) or strange location (spatial).
  • Static Risk Tiers: Risk bounds are fixed; thresholds do not adjust to ongoing behavioral logs.
  • Lagging Containment: Requires manual administrator actions with zero real-time remediation.

ACASTM Security Model

  • Context-Aware Triggers: Evaluates temporal off-hours (+40) and spatial IP geoshifts (+60).
  • Real-time Telemetry Analytics: Recalculates risk dynamically on click/report events.
  • Zero-Trust Interventions: Locks sessions instantly at Score >= 75 and deploys remediation.
